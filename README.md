//Book Search

A simple web app to search for books by name. It shows the title, the author, the first publish year, and the cover image of each result.
The data comes from the Open Library Search API.

Live Demo

(https://book-search-emgw.onrender.com/)

//Features

Search any book by name

Shows title, author, first publish year, and cover image

Handles books with no cover image or no author

Library-themed background with transparent cards

Built With:

Node.js
Express
EJS (templates)
Axios (API requests)
HTML and CSS
